Sep10-Anson-and-Ethan's-journey-to-Looksmaxxing

What I made here was a game to provide for my very own adventure.

Context

The point in making this game was to test my own creative ability with a collaborator and Git. While in the making of this project it helped me to practice uses git commands and links as I had to link different pages of a site to one another and tinker with each one.

Challenges

The diffuculty with this project was with the creativity as although we had a idea to base off of it was hard to find what terms made sense in that context especially when my partner and I were new to the topic. Another problem that came up was with links in different folders as I attempted to link a text file to 2nd text file while it was in a different folder which failed to work.

Next steps

Steps I would have taken if given much more time was transfer all the work onto a html version as to customize the CSS and animation for every interaction. Another thing would be for me to find out how my link between 2 text files while 1 was in a folder didn't work as that forced me to move it into the same directory.
