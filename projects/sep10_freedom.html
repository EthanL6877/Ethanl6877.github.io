Freedom Project

Context

This page represents a year’s worth of work on a passion project that my collaborator and I built from the ground up. Inspired by our shared interest in engineering and technology. From understanding the fundamentals of HTML and CSS to exploring website design principles and user experience, every stage of this project challenged us to grow as developers. What began as a simple idea gradually evolved into a fully developed website that reflects both my and my partners creativity and technical abilities. More importantly, this project taught us the value of "LOYO"-> (Learn On Your Own).For SEP students you may have heard of this before but this project also helped "Git" ready for the future and is tha basis to which I can look back on and improve one it as a student under SEP from HSTAT.

Challenges

  • A challenge was I had were controlling how much time to give my partner and I when presenting for this project. An elevator pitch was needed in order to present this freedom project and while we did make Google slides to make for this and plan of action wasn't well cordinated.
  • A challenge I had was finding out how Jquery functions work as it touched upon java script but implemented simple html. I found this extremely confusing

Take aways

  • If talking doesn't work use actions to demonstrate
  • Always remember code is based on a equation so if there is a input there will be a output

While this year has been a ride with meeting new friends, creating projects, learning, and creating something of my own I only wish I had the conviction and determination I have at the end of the year in the beginning and for my future self is to see this. So if your reading this Stay determined, stay strong, and always "LOYO."
